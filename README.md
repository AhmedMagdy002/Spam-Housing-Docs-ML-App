# Spam-Housing-Docs-ML-App

A Tkinter-based application for evaluating machine learning models across multiple domains with visualization features for better understanding of model performance.

## Features

This application includes three main modules:

###  Email Spam Detection
- Classifies emails as spam or not spam.
- Models used: K-Nearest Neighbors (KNN), Decision Trees, Naive Bayes.
- Includes accuracy reports and confusion matrix visualization.

###  Housing Price Prediction
- Predicts housing prices using a Linear Regression model.
- Visualizes actual vs. predicted prices.
- Includes R-squared score calculation.

###  Document Classification
- Clusters documents using K-Means.
- Uses TF-IDF for feature extraction and PCA for dimensionality reduction.
- Visualizes clustering results.
- Dataset: BBC News Archive (2225 documents from 5 topics: business, entertainment, politics, sport, tech).

##  Datasets
- **BBC News Archive**: 2225 documents across 5 categories.
- **Email Dataset**: Text emails labeled as spam/ham.
- **Housing Dataset**: Includes features like area, bedrooms, furniture status, and proximity to main roads.
